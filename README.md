## 🤍 Currently Collaborating On

### ୨୧ Lamb's Plate — With Lichume

**Good Food Shouldn't Go To Waste.** 🍽️

Lamb's Plate is a collaborative software project I'm working on with **Lichume Standard**. The idea is to help rescue surplus food by connecting businesses with food they cannot sell to people who can reserve it and collect it before it goes to waste.

Restaurants, shops, and wholesalers can potentially make surplus food available, while people nearby can browse listings, reserve portions, and collect them within the specified pickup window.

The project is currently in its **foundation stage**. The initial server setup, health endpoint, and automated test workflow are in place, while the main MVP features are planned for development.

**Planned MVP Features:**

- **Donor Side:** Create food listings, manage your own listings, and provide collection details.
- **Receiver Side:** Browse available food, reserve portions, and confirm collection.
- **Reservation Rules:** Prevent over-reserving, reject reservations after pickup windows close, and handle competing reservations for the final available portion.

**Tech Stack:** Java 21 · Javalin · Maven · JUnit 5 · GitHub Actions

**My Planned Contribution:** Receiver-side functionality, including the flow for browsing listings and reserving available food.

**Collaboration Experience:** Working with another developer, contributing to a shared codebase, following branch and review practices, and building towards a common goal.

[![Explore Lamb's Plate](https://img.shields.io/badge/Explore%20Project-Lamb's%20Plate-777783?style=for-the-badge&logo=github&logoColor=white)](https://github.com/standard-archive/lambs-plate)

*This project is a work in progress. The planned MVP features are not yet presented as completed functionality.*

## 🎓 School Project Experience

### ୨୧ Robot Worlds — From Greenfield To Brownfields

**Learning To Build Software, Then Work With What Already Exists.** 🤖

As part of my studies at WeThinkCode_, I worked on **Robot Worlds**, a collaborative Java school project that took me through both greenfield and brownfields development.

The greenfield stage introduced me to building software from the ground up. The brownfields stage challenged me to understand an existing codebase, make changes carefully, and consider how new functionality affects what is already there.

Through this school project, I gained experience with:

- **Greenfield Development:** Understanding the process of starting a software project from scratch.
- **Brownfields Development:** Navigating and improving an existing codebase.
- **Java And Maven:** Working with Java code and a Maven-based project structure.
- **REST APIs:** Learning how software components communicate through API endpoints.
- **Databases:** Working with SQLite in the project environment.
- **Docker:** Exploring containerisation as part of the development workflow.
- **Testing And Debugging:** Investigating errors, checking expected behaviour, and making changes carefully.
- **Collaboration:** Working within a shared project and learning to understand code beyond my own contributions.

**Key Takeaway:** Software development isn't always about starting with a blank screen. Sometimes, it's about understanding an existing system and improving it without breaking what works.

*Robot Worlds is school project experience, separate from my personal projects and my collaboration on Lamb's Plate.* 🩶
